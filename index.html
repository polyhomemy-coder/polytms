How to set up Supabase (click)
  1. Create a free account at supabase.com and create a new project.
  2. Open Project Settings → API and copy the Project URL + anon public key.
  3. Open SQL Editor, paste the SQL from the button above, then Run.
  4. Come back here, paste URL + key, and click Connect & Verify.
